A two-line micro poem about light and morning, written for the
[Two Lines of Morning Light](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5)
bounty on make.fun.

`main.py` (Python 3.13, stdlib only) writes the poem to `/output/entry.txt`:

> Light unthreads the curtain's hem, stitch by stitch,
> and the dark gives the room back, piece by piece.

One image — morning light arriving at the curtain's hem — and the
second line opens it: the dark hands the room back, piece by piece.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
